# Android TV 0.1.2 Release Record

Date: 2026-05-17

Device target: X10 / Android TV low-end board

Home API: `https://oc.goods-editor.com/api`

## Release Scope

This is the next acceptance build after `0.1.1`. It keeps the public APK baseline and adds the current service-center payment surface plus vendor-system handoff material.

Included:

- Service center package cards for big membership and AI service packages.
- WeChat Native payment QR entry through the `codex-web` payment gateway.
- AI-service paid state display after a successful `0.01` CNY order.
- Longer payment polling window for real QR payment on TV.
- Home model-renewal payment order API contract updates.
- Vendor system-permission HTML brief for X10 system-level follow-up.

Out of scope for this build:

- Self-owned full AirPlay / Miracast / Wi-Fi Display mirroring stack.
- Silent system OTA.
- Privileged freezing or forced stopping of system packages.
- Projection hardware APIs such as focus, keystone, brightness, fan, and temperature.

## Remaining Known Limits

- AI package payment has been verified paid and active; VIP package still needs a separate paid-path check.
- WeChat async notify should still be verified independently; current Home settlement has an active order-status fallback.
- Real phone casting remains Lebo-backed for full mirror behavior; self-built DLNA covers lightweight media receiving only.
- OTA needs the storage publish and device install/report loop before it can be treated as production-ready.
- System-level projection, diagnostics, hardware control, and privileged process policy remain vendor-blocked.
