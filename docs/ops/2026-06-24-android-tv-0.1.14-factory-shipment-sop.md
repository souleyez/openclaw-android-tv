## 4. 标准安装步骤

### 4.1 ADB 安装

```powershell
adb devices
adb install -r openclaw-tv-0.1.14-2026062401-3128-platform-release-signed-20260624-221225.apk
```

期望输出：

```text
Success
```

### 4.2 固化默认 Home

安装后必须执行：

```powershell
adb shell cmd package set-home-activity --user 0 com.openclaw.tv/.MainActivity
```

期望输出：

```text
Success
```

验证默认 Home：

```powershell
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

期望包含：

```text
com.openclaw.tv/.MainActivity
```

### 4.3 首次启动和前台验证

```powershell
adb shell input keyevent HOME
adb shell dumpsys window windows | findstr /i "mCurrentFocus mFocusedApp"
adb shell dumpsys activity activities | findstr /i "mResumedActivity"
```

期望包含：

```text
com.openclaw.tv/com.openclaw.tv.MainActivity
com.openclaw.tv/.MainActivity
```

## 5. 出厂验收步骤

工厂每个固件批次至少抽测一台 fresh 机器：

1. 恢复出厂或使用全新烧录机器。
2. 安装本 APK。
3. 设置默认 Home。
4. 连网，确认首页可进入。
5. 按遥控器 Home，确认回到 OpenClaw 首页。
6. 断电冷启动，确认启动后进入 OpenClaw 首页。
7. 执行 `resolve-activity MAIN/HOME`，确认默认 Home 未丢失。
8. 检查权限：

```powershell
adb shell dumpsys package com.openclaw.tv
```

需要确认：

```text
versionCode=2026062401
versionName=0.1.14
android.permission.INSTALL_PACKAGES: granted=true
android.permission.RECEIVE_BOOT_COMPLETED: granted=true
```

9. 打开首页 APP 位，确认默认 APP 和 `+` 应用列表可用。
10. 测试投屏入口。当前 iOS/小米投屏体验仍以乐播兜底为主，工厂镜像需要保留并允许乐播正常运行。
11. 连续运行 4 小时，观察首页、投屏、应用打开和返回首页后的资源表现。
12. 记录设备序列号、固件版本、APK SHA-256、验收截图。

## 6. OTA 验收要求

本地安装通过不等于 OTA 出货闭环完成。正式发工厂前，至少要跑一次线上 OTA：

1. 在 home 平台发布一个更高 `versionCode` 的 `full_apk` release。
2. 设备从 `https://oc.goods-editor.com/api` 获取 manifest。
3. 设备后台下载 APK。
4. 设备校验 SHA-256。
5. 空闲时尝试静默安装。
6. 如无权限，回落到系统安装器 UI。
7. 安装后重启，确认进入新版本。
8. 平台收到 `installed` 或失败状态。

当前测试机已授予 `INSTALL_PACKAGES`，但工厂其他固件仍必须复测。不同系统签名、不同预装位置、不同权限白名单都会影响真静默安装。

## 7. 工厂镜像建议

优先方案：

- APK 预装为系统应用或 priv-app。
- 固件内置默认 Home 指向 `com.openclaw.tv/.MainActivity`。
- 权限白名单授予安装、开机、自启动、必要后台能力。
- 保留乐播或等价投屏服务，并确认不会被系统清理。

可接受的工程试装方案：

- 使用 ADB 或工厂工具安装 APK。
- 安装后执行 `set-home-activity`。
- 出货前执行一次断电冷启动验收。

不建议：

- 只把 APK 当普通用户应用安装但不设置默认 Home。
- 工厂机器混装 debug、factory-pilot、3128-platform 三种签名包。
- 降级安装旧包作为回滚方式。Android 不允许降低 `versionCode` 覆盖安装，回滚包也必须使用更高 `versionCode`。

## 8. 已知限制

- USB ADB 在本次重启后没有自动重新枚举，后续通过 `192.168.1.2:5555` 无线 ADB 完成验收。工厂如果依赖 USB ADB，需要复查驱动和 USB 调试策略。
- 当前自建投屏能力不能等价替代乐播。量产镜像若删除或限制乐播，投屏体验会下降。
- `oc.goods-editor.com` 当前健康检查正常，但证书有效期需要持续监控和自动续期。
- 恢复出厂后如果 APK 位于 `/data/app`，应用会被清除。量产预装应使用系统镜像或工厂 provisioning 流程保证恢复后仍存在。
- 后台清理、冻结第三方应用、系统级投屏、系统 OTA 和专项日志仍依赖厂商系统权限或固件接口。

## 9. 回滚口径

如果本版在工厂 fresh 机器上失败：

1. 保留设备，不要直接恢复现场。
2. 导出 `dumpsys package com.openclaw.tv`。
3. 导出 `dumpsys window windows` 和 `dumpsys activity activities`。
4. 记录 `cmd package resolve-activity MAIN/HOME` 输出。
5. 截图并记录固件版本、设备 SN、安装方式。
6. 暂停扩大安装范围。

如果需要恢复旧体验：

- 不建议直接降级旧 APK。
- 应发布更高 `versionCode` 的恢复包。
- 或由工厂刷回前一版完整固件镜像。
