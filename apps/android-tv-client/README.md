# Android TV Client Skeleton

这是 OpenClaw Android / Android TV Flutter 客户端骨架目录。

建议后续初始化为 Flutter 工程，并按以下模块拆分：

- `lib/app_shell`
- `lib/core`
- `lib/features/tv_home`
- `lib/features/voice`
- `lib/features/control`
- `lib/features/account`
- `lib/features/device_sync`
- `lib/features/settings`
- `android/app/src/main/kotlin/.../plugins`

当前目录仅用于先固定工程结构与模块边界。
